# Arte do HexaAlerts

Arquivo: [hexa-alerts-modernista.png](hexa-alerts-modernista.png).

Banner criado com o recurso integrado **imagegen**, seguindo a identidade modernista de **Marco Picanço**.

## Conceito

A bola de futebol representa o domínio da aplicação. O hexágono remete ao nome HexaAlerts, e os sinais conectados representam alertas, estatísticas e eventos.

A composição segue a mesma direção visual dos outros projetos: tipografia próxima de Inter, alinhamentos consistentes, espaço generoso e geometria discreta.

| Uso | Cor |
| --- | --- |
| Fundo marfim | `#F7F4EE` |
| Texto grafite | `#252B2A` |
| Destaques terracota | `#B63825` |
| Texto secundário | `#596158` |
| Linhas de construção | `#D8D5CB` |

A frase “Do primeiro lance ao apito final” foi extraída da apresentação deste projeto. A assinatura “Clareza na ideia. Precisão na entrega.” e o endereço marcopicanco.com conectam a arte à identidade do autor.

Referência de estilo: [banner modernista do projeto debian-install](https://github.com/marcopicanco-dev/debian-install/blob/main/docs/images/debian-modernista.png).
